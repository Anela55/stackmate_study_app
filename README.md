📚 StackMate — Smart Study Companion

StackMate is a simple, interactive study app that helps students organise tasks, stay focused, and improve their study habits.

Features

- 📝 Study task manager
- ⏱️ Focus timer
- 🧠 Interactive quizzes
- 📖 Study methods and reflections
- 🎨 Customisable theme
- 💾 Local data storage

Technologies

- HTML
- CSS
- JavaScript

Purpose

To help students study smarter, stay organised, and build consistent learning habits.

Study smarter. Stay focused. Build consistency.
